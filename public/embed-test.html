Testseite – so sähe es auf einer Vereins-Website aus

Diese Seite gehört nicht zur App. Sie prüft nur das einbettbare Beitragsfenster. Unter jedem Fenster muss der Text „Ende des Fensters“ direkt anschließen – ohne Lücke und ohne zweiten Scrollbalken.

Aktuelles aus dem Verein

Alle Beiträge von D001: /embed?kunde=D001

↑ Ende des Fensters (alle Beiträge).

Neues aus der Tennis-Abteilung

Nur eine Abteilung: /embed?kunde=D001&kategorie=Tennis

↑ Ende des Fensters (Tennis).

Einbettcode für WordPress

Für den Block „Individuelles HTML“. Gilt erst nach der Freigabe, wenn club.onlang.de/embed live ist.

<iframe class="onlang-beitraege"
  src="https://club.onlang.de/embed?kunde=D001&amp;kategorie=Tennis"
  title="Neues aus der Tennis-Abteilung" loading="lazy"
  style="width:100%;border:0;height:600px"></iframe>
<script>
window.addEventListener("message", function (e) {
  if (e.origin !== "https://club.onlang.de") return;
  if (!e.data || e.data.typ !== "onlang-hoehe") return;
  var fenster = document.querySelectorAll("iframe.onlang-beitraege");
  for (var i = 0; i < fenster.length; i++) {
    if (fenster[i].contentWindow === e.source)
      fenster[i].style.height = Math.ceil(e.data.hoehe) + "px";
  }
});
</script>
